# pluginscore
PluginsCore - этот модуль представляет собой базовый AMX Mod X модуль под названием "Plugins Core", который предназначен для предоставления информации о своей загрузке и готовности к работе другим плагинам. Основная его функция - экспортировать нативный метод is_core_module_ready, который позволяет другим плагинам узнать, успешно ли загружен и инициализирован "core_module".

Дальнейшая разработка модуля, производится.
Идея не заброшена, так же буду рад увидеть/услышать какую либо критику/помощь.
